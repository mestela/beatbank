# Beat Bank 0.1.6

This community build updates Beat Bank for current Schwung and keeps the
original 457-pattern library and MIDI engine.

- Replaces the broken canvas preview with a full-screen pattern editor.
- Places voice and genre controls around the pattern grid using Schwung's mini font.
- Adds scrollable pattern, pad, genre, and Note Map lists. Touch a choice knob,
  turn a knob or the jog, then release to choose; Back cancels.
- Corrects the installation package and documents fixed MIDI-channel routing
  when recording Beat Bank into a Move clip.

Requires Schwung 1.0.0 or newer. The original project is by Mission Minnow;
this release is intended as a maintained fallback while the upstream fix is
reviewed.
